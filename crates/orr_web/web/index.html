Orrery web client

The same deterministic simulation as the native clients (wasm, in a Web Worker), joined to a relay room over WebTransport or WebSocket, drawn with orr_render on WebGPU (WebGL2 fallback) or, without either, on a 2D canvas (&render=2d forces it). Arrow keys move, space fires (arena); in the physics game the arrows move the paddle, Q/E spin it and space shoots. Add &bot=1 to let the scripted bot play.
