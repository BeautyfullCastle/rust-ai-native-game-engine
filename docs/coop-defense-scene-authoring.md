# Create a Stormglass starting scene

Create a new Scene without running an editor/ERP host or hand-editing YAML:

```sh
python3 tools/create_coop_defense_scene.py \
  --wasm dist/coop-defense-web/game.wasm \
  --starting-gold 250 --reactor-hp 75 --last-wave 3 \
  --output short-game.scene.yaml
```

Use a **trusted locally built** CoopDefense WASM. The tool executes it in Node;
this is not a sandbox for untrusted WASM. Python 3.11+, Node and an existing build
are required; the command does not build, download, start a server or upload.

The optional values are starting gold per board (0–10000, default 150), reactor
HP (1–1000, default 30), and the last wave (1–10, default 10). Last wave selects
a prefix of the existing campaign, not new enemies or wave rules. This tool
emits only the existing Scenario/Campaign singletons and no entities. It does
not edit existing scenes, set WavePacing or change simulation/engine contracts.

The exact generated bytes pass the same engine admission used by the offline
packer before publication. Standard output is its JSON receipt with scene/WASM
SHA-256, scene byte count and initial checksum; hashes identify bytes, not trust.
Failure exits nonzero. The output directory must already exist. Existing files,
including symlinks, are never overwritten. Inputs must be bounded regular files;
symlink paths and special files are rejected. Publication uses the existing
Linux/POSIX no-clobber hard-link helper; unsupported filesystems fail closed.
Use trusted, quiescent directories. A forced interruption may leave a temporary
file; there is no destructive cleanup or overwrite retry.

## Play and deliver

Select the saved file in the browser game's **저장 장면 불러오기** control, or pass
it to the native player's existing `--scene` option. Restart retains its settings.
For one-file delivery, use the existing packer:

```sh
python3 tools/pack_coop_defense_offline.py dist/coop-defense-web \
  --scene short-game.scene.yaml --output short-game.html
```

Use matching trusted build assets. Loading a file in the browser alone does not
embed it into an exported HTML. ERP editing/Undo/Save remains the existing path
for editing a document; this CLI only creates a new one.

## Focused verification

```sh
ORR_DEFENSE_WASM=/absolute/path/to/trusted/game.wasm \
  python3 -m unittest discover -s tools -p test_create_coop_defense_scene.py -v
```

The suite covers option bounds/types, deterministic output, no-clobber and file
safety, validator failure, and actual saved-byte WASM loading/restart. Without
the environment variable, actual-engine cases are explicitly skipped. Node/WASM
and mock-DOM tests do not establish real browser, GPU or native-window acceptance.
