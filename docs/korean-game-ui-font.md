# Korean game UI font provenance

`assets/game_ui_font` is a local, data-only Orrery package named
`korean-game-ui`, version `1.0.0`, engine constraint `^0.0.1`, with no
capabilities, dependencies, executable hooks, or runtime system-font lookup.
The game UI consumes `OrreryKoreanUI.otf` through verified
`Project::read_asset("korean-game-ui", "OrreryKoreanUI.otf")` after package
installation. The installed upstream font is a **regeneration input only**.

## Coverage and size

The generated font has exactly 11,634 cmap codepoints:

- U+AC00–U+D7A3: all 11,172 modern precomposed Hangul syllables
- U+1100–U+11FF: 256 Hangul Jamo
- U+3131–U+318E: 94 Hangul Compatibility Jamo
- U+0020–U+007E: 95 printable ASCII characters
- 17 additional spacing, punctuation and arrow codepoints, explicitly listed
  in `font-manifest.json`, including U+00B7 middle dot used by the UI

The font is 1,891,888 bytes, below the UI's 16 MiB limit and the package reader's
64 MiB per-file limit. The SHA-256 is
`91c7e75ac1b54a3571a305d259a2f486b88289853baef90753506855f5c5dd08`.
`corpus.txt` records current Korean UI labels and representative boundary/rare
syllables, Jamo and punctuation. Coverage is not restricted to this corpus.

This is not a full CJK font: Hanja, extended archaic Hangul Jamo, emoji and
other unlisted scripts are not covered. Codepoint coverage does not establish
renderer shaping, line wrapping, input-method behavior, accessibility or visual
quality. In particular, Jamo shaping requires compatible renderer support.
The separate GPU/UI validation must establish actual screen rendering.

## Reproduction and verification

Requires Python and exactly FontTools 4.61.1; no network download is performed.
The source hash and source family/version are verified before generation:

```sh
python tools/subset_game_ui_font.py
python tools/subset_game_ui_font.py --check
# Optional alternate copy of the identical, hash-verified input:
python tools/subset_game_ui_font.py --source /path/to/NotoSansCJK-Regular.ttc --check
```

The recipe retains upstream license/name attribution and applicable layout
features, subsets the explicit Unicode set, renames the derivative, sets both
OpenType timestamps to 2082844800 (Unix epoch expressed in OpenType epoch
units), and saves with canonical/reordered tables. Each invocation independently
generates twice and compares complete bytes, parses/decompiles the saved font,
checks exact cmap coverage and non-.notdef mappings, and checks corpus coverage.
`--check` additionally compares generated bytes and provenance metadata against
the committed artifacts without replacing them. A different FontTools version
is rejected, rather than silently claiming byte-for-byte reproducibility.

No visual-render verification is claimed by this package check. Installation,
package tamper detection, renderer acceptance and GPU screen evidence are
integration checks owned by the game UI implementation.
