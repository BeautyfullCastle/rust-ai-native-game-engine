# Mesh scenes in the editor

With the optional `mesh-navigation` feature enabled, the editor can create and open local MeshNavigation scenes from its normal Physics startup. Use **File → New mesh scene…** to choose a new `.scene.yaml` path, or **File → Open mesh scene…** to open an existing admitted mesh scene. Both actions are available for clean local Physics and MeshNavigation sessions; they do not require starting the editor with a MeshNavigation-specific command-line bootstrap.

The editor validates a candidate before replacing the current session. Opening an invalid or unsupported scene leaves the current session in place. Creating or opening a scene is refused while the current document or supported authoring state has unsaved changes, an unfinished transaction, or another blocking operation. Save or undo the changes before retrying. These transitions are local-editor workflows; they do not change remote-host or general scene-loading policy.

In a MeshNavigation scene, use **Static-mesh navigation** to import or create the walkable mesh, then **Create ramp and bridge** and **Place mesh agent** to author a starter graph and agent. Save the scene with **File → Save**. The graph and navigation-agent state are scene data and are checked when the scene is opened and when Play starts.

Optional cosmetic agent art is edited in **Mesh agent art**. Load a static model from a local package source, apply its offset and scale, then explicitly **Save agent art**. This writes a scene-specific `.mesh-art.json` sidecar next to the scene. The sidecar embeds the validated cooked model and license text; it does not install the package or make it a current dependency. Keep the scene and sidecar together when moving the scene. If the art source directory is unavailable, a saved sidecar can still render its embedded model. Unsaved art changes must be saved or undone before changing scenes.

The sidecar's package, asset, and license hashes record the inspected source as provenance. They are not proof of publisher identity, current installation, or legal rights. The sidecar's cooked-model digest detects accidental payload changes but is not an authenticity signature. Use trusted, stable local directories: path and prior-hash checks detect observed conflicts, but file-path operations are not capability-safe or linearizable against hostile concurrent replacement and do not promise crash/power-loss durability.

MeshNavigation uses a static triangle graph and point agent; this workflow does not create a general-purpose character controller or collision system. The separate opt-in `mesh-export` feature adds [standalone Mesh Player export](editor-mesh-export.md); `mesh-navigation` alone does not enable it. Saving and reopening tests the current graph and scene admission rules, not exhaustive reachability across every possible intermediate position or runtime condition.
